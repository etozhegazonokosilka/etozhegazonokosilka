## ⭐ Featured Projects

### [Bag Price Analyzer API](https://github.com/etozhegazonokosilka/bag-price-analyzer)

An API for estimating the market value of luxury handbags from a photo.

The system combines Google Lens search, marketplace-specific web scraping, AI candidate filtering, OpenCLIP visual similarity and robust price analysis.

**Main technologies:**

`Python` · `Flask` · `SerpAPI` · `OpenCLIP` · `Redis` · `RQ` · `Web Scraping`

> A sanitized portfolio version of a commercial project.

### [Mafia Web Game](https://github.com/etozhegazonokosilka/mafia-game)

A multiplayer browser implementation of Mafia with rooms, hidden roles, chat and real-time game phases.

The application includes authentication, player profiles, statistics, levels, a leaderboard, an administration panel and WebSocket state synchronization.

**Main technologies:**

`Python` · `FastAPI` · `React` · `TypeScript` · `Tailwind CSS` · `WebSocket` · `SQLAlchemy`

> A sanitized portfolio version without production data or secrets.
